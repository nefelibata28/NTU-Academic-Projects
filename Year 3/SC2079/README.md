# SC2079 – Multidisciplinary Design Project

This is a **group project-based module** focused on designing and building a robotic system through a multidisciplinary engineering approach. The project combines hardware and software development, system integration, and team collaboration.

---

## Project Overview

This group project involves building a robotic system that can:
- Autonomously explore/traverse a known area detecting images displayed in the arena
- Perform obstacle avoidance using visual markers (bullseyes)  
- Transmit and receive control signals from a mobile device  
- Simulate the physical robot and its algorithms in software
