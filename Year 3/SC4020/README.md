 ## 1. [Project 1](https://github.com/nefelibata28/NTU-Academic-Projects/tree/main/Year%203/SC4020/Project%201)- Clustering Analysis on Multiple Datasets

### Project Highlights:
- Comparative analysis of three clustering methods: K-Means, DBSCAN, and Bayesian Networks.
- Applied on three diverse datasets: NBA Shots, World Happiness Report, and Mall Customer Segmentation.
- Performance evaluated using Silhouette Score and Davies-Bouldin Index.
- Insights gained into the strengths, limitations, and suitability of each method for different types of data

### Project Overview:
This project involved selecting multiple datasets and applying data preprocessing, clustering, and classification techniques. The primary focus was on clustering, a key aspect of unsupervised machine learning, which groups similar data points to uncover patterns, trends, or hidden structures within datasets.

Three algorithms—K-Means, DBSCAN, and Bayesian Networks—were implemented and evaluated across datasets of varying sizes and characteristics. The main objective was to assess the effectiveness of these methods and provide actionable insights based on the clustering results. Each algorithm was analyzed for its ability to reveal grouping patterns and predictive performance. Evaluation metrics were applied to compare their strengths and suitability across different types of data.

### Objectives
- Explore clustering as a tool for grouping similar data points.
- Compare the performance of K-Means, DBSCAN, and Bayesian Network clustering.
- Analyze datasets from different domains (sports, socio-economic indicators, and retail).
- Evaluate clustering quality using Silhouette Score and Davies-Bouldin Index.
- Identify the most suitable clustering approach for each dataset.

### Methodology

### Step 1: Data Preprocessing
- Feature selection based on relevance to clustering objectives.
- Standardization using StandardScaler or MinMaxScaler.
- Encoding categorical variables where necessary (e.g., gender).

### Step 2: Clustering Implementation
- K-Means: Partitioning-based algorithm that clusters data around centroids.
- DBSCAN: Density-based algorithm that identifies clusters and noise without predefining the number of clusters.
- Bayesian Networks: Probabilistic clustering that models dependencies among variables.

### Step 3: Evaluation Metrics
- Silhouette Score: Measures cohesion and separation of clusters (range -1 to 1).
- Davies-Bouldin Index (DBI): Measures cluster compactness and separation (lower is better).

### Step 4: Visualization
- 2D and 3D plots for cluster analysis.
- PCA for dimensionality reduction where necessary.
