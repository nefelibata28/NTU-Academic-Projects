
## SC1015 Group Project – Steam Games Clustering

## Overview
This project uses **unsupervised learning** to uncover hidden patterns in the [Kaggle Steam dataset](https://www.kaggle.com/datasets/nikdavis/steam-store-games).  

My part focused on **DBSCAN**.  

The full project can be viewed on https://github.com/nefelibata28/usg

The goal is to help **game developers make better games** by:  
- Identifying hidden patterns in player trends  
- Discovering common features within player subgroups  
- Understanding why players are attracted to certain games
