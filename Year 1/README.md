## 🖥️ SC1003 – Introduction to Computational Thinking & Programming
### Assignment 1: Flight Seating Reservation System
- Console-based program to manage seat reservations for a small airline (5 seats).  
- Features:
  - Assign seat (prevents double booking, checks availability)
  - List all taken seats
  - Remove/cancel seat assignment
  - Exit program
- Concepts used: **structures, arrays, functions, menu-driven programming**  
- [Project](https://github.com/nefelibata28/NTU-Academic-Projects/tree/main/Year%201/SC1003/SC1003_%20Assign1_Flight%20Reservation%20System)

### Assignment 2: MACD Trend Reversal Trading System
- Trading system based on **MACD (Moving Average Convergence Divergence)** indicator.  
- Implemented in Python (assignment crossover).  
- Features:
  - Calculate MACD, signal line, histogram
  - Generate buy/sell signals from crossovers
  - Backtest system returns vs. benchmark returns
  - Visualize equity curves, MACD signals, and trend strength
- Concepts used: **pandas, numpy, matplotlib, seaborn, backtesting logic**  
- [Project](https://github.com/nefelibata28/NTU-Academic-Projects/tree/main/Year%201/SC1003/SC1003_Bhati%20Nancy_assign2)
