## Project Highlights
- Full-stack AI-assisted web-based scheduling assistant
- Supports multiple timetable input formats (manual, image upload, .cal, Google Calendar)
- Comprehensive requirements analysis using UML models
- Includes use case diagrams, class diagrams, sequence diagrams, and dialog maps
- Designed following Software Engineering best practices
- Implemented using HTML, CSS, JavaScript, Python, Firebase, and modern frameworks (React)
- Secure authentication with password recovery
- White Box Testing conducted for core system components

## Project Overview
Project Compass is a full-stack software engineering project developed for SC2006 – Software Engineering at Nanyang Technological University (NTU).

The project aims to design and implement an intelligent scheduling system that helps users manage appointments, resolve event clashes, and optimize time usage. The system was developed following a structured software engineering lifecycle, beginning with requirements analysis and UML modeling, and progressing to system implementation and testing.
[Project Instructions](https://github.com/nefelibata28/NTU-Academic-Projects/blob/main/Year%202/SC2006/SC2006%20Lab%20Manual.pdf)

## Objectives
The main objectives of this project are:
- To refine and formalize system requirements through detailed use case analysis
- To construct a Conceptual Model representing the core domain entities
- Apply UML techniques to model system structure and behavior
- Implement a secure and scalable web application
- Integrate external services such as Google Calendar
- Validate system correctness using White Box Testing

## System Features
- User login, signup, and password recovery
- Secure authentication using Firebase
- Multi-format timetable input and consolidation
- Manual event creation with validation rules
- Event clash detection and rescheduling alerts
- Travel time allocation using Google Maps
- Google Calendar synchronization
- Export schedules to PDF / JPG

## Methodology
The project follows a UML-driven and iterative development methodology:

### 1. Requirements Analysis
- Functional and non-functional requirements specification
- Detailed use case descriptions

### 2. System Modeling
- Conceptual Model (Class Diagrams)
- Dynamic Model (Sequence Diagrams and Dialog Maps)
  
### 3. Implementation
- Frontend development using HTML, CSS, JavaScript
- Backend logic using Node.js and Python
- Firebase integration for authentication and data storage

### 4. Testing
- White Box Testing for critical logic and control flows
- Validation of authentication, scheduling, and conflict detection modules
