# SC3061 - Human Computer Interaction

## Multiversal Studios Amusement Park Kiosk – UX/UI Design Project

---

## Project Overview
The goal of this project is to design an interactive kiosk interface for Multiversal Studios amusement park that helps visitors plan their day efficiently. The kiosks provide an intuitive, engaging, and interactive experience for visitors, allowing them to select rides, shows, and eateries while factoring in real-time wait times, distances, and group preferences. The project emphasizes usability, user experience, and creativity in interface design.

**Note:** All assignments in this project — lo-fi prototype, usability evaluation, and hi-fi prototype are **individual-based assigments**.

## Problem Statement
- Visitors at Multiversal Studios face two main challenges:
  - Long, unpredictable waiting times for popular rides.
  - Difficulty navigating the park and planning activities effectively, leading to indecision or dissatisfaction.
- The kiosk aims to solve these problems by:
  - Offering personalized recommendations and optimized itineraries.
  - Supporting multi-user interaction for families or groups.
  - Providing dynamic updates based on real-time information and visitor feedback.

## Target Users, Goals & Pain Points
- Target Users:
  - Families and groups visiting the park
  - New visitors unfamiliar with the park layout and activities
  - Solo visitors seeking efficient planning

- User Goals:
   - Quickly discover attractions, shows, and eateries
   - Plan and organize a personalized itinerary
   - Minimize waiting times and avoid congestion
   - Experience an enjoyable, intuitive, and interactive interface

- Pain Points:
   - Overwhelming number of options causing confusion
   - Long wait times and inefficient planning
   - Difficulty coordinating plans among multiple visitors
   - Limited guidance for optimizing park experience

## Required Key Features of Kiosks
- Interactive Park Map – Displays rides, shows, and eateries with images, descriptions, distances, and predicted wait times.
- Multi-User Interaction – Allows groups to plan activities simultaneously.
- Dynamic Scheduling – Optimizes itineraries based on user choices and real-time data.
- Memory & Adaptability – Remembers past interactions and adjusts schedules dynamically.
- Proactive Recommendations – Suggests changes based on visitor mood, group dynamics, or delays.
- Intuitive Interface – Easy-to-understand interface that follows UI/UX principles and enhances user experience.
- Multilingual Support – Provides content and navigation in multiple languages, allowing visitors from around the world to use the kiosk comfortably.
- Help & Support – Offers a comprehensive help section with common FAQs, step-by-step guidance, and an AI assistant for instant troubleshooting. Users can also connect with support staff for complex issues.
